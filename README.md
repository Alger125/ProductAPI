# Product API

API robusta construida con **.NET 8**, **Clean Architecture** y el patrón **CQRS**.

## 🚀 Progreso del Proyecto (PRD)

- [x] **Estructura Base**: Solución de .NET y proyectos de arquitectura.
- [x] **feature/product-domain**: Entidades (Product, Category, Brand, Review), reglas de negocio encapsuladas y Pruebas Unitarias.
- [ ] **feature/ef-core-sqlserver**: Configuración de EF Core, SQL Server, DbContext y migraciones.
- [ ] **feature/mediatr-cqrs**: Configuración de MediatR (Commands, Queries, Handlers).
- [ ] **Endpoints**: Create, Get, Update, Delete Product.
- [ ] **feature/product-validation**: FluentValidation.
- [ ] **feature/global-errors**: ProblemDetails.
- [ ] **feature/docker-api**: Docker Compose para la API y DB.
- [ ] **feature/authentication**: JWT y roles.
- [ ] **feature/github-actions**: CI/CD pipeline.
